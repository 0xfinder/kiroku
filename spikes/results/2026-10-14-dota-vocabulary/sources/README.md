# Source research, 2026-10-14

Time-boxed to the free sources named in issue #28; no Steam key or paid API.

- [dotaconstants heroes](https://raw.githubusercontent.com/odota/dotaconstants/master/build/heroes.json): HTTP 200, 127 heroes, every entry has localized_name. [items](https://raw.githubusercontent.com/odota/dotaconstants/master/build/items.json): HTTP 200, 501 entries, ten lack dname. These committed projections retain consumed fields and unnamed entries; all gameplay stats were discarded.
- [OpenDota teams](https://api.opendota.com/api/teams): HTTP 200. Spirit substring discovery also found old Team. Spirit (last match 2019) and w33ha earthspirit (2017), both with no current players. The file retains just these four discovery candidates and consumed fields. Production matches whole words in names/tags, strips the conventional `Team ` prefix, and prefers recent duplicate names.
- [Spirit players](https://api.opendota.com/api/teams/7119388/players) and [Yandex players](https://api.opendota.com/api/teams/9823272/players): HTTP 200, 33 and 13 rows; five and six marked current. DM remains current alongside AMMAR_THE_F. No attempt to infer the exact five playing from this API. Never equate account 218231587 (`not_me`) with Collapse.
- [proPlayers](https://api.opendota.com/api/proPlayers): HTTP 200, 5,666 rows, no exact ATF handle and no real_name field. Includes AMMAR_THE_F, decorated watson and Maladych. Rejected: larger, no useful real-name information. The profile/avatar dump is deliberately not committed; research counts are retained.
- [Liquipedia API terms](https://liquipedia.net/api-terms-of-use): HTTP 200. Used one reusable httpx client with `Accept-Encoding: gzip` and `User-Agent: Kiroku/0.1 (Dota vocabulary research; https://github.com/0xfinder/kiroku/issues/28; contact: https://github.com/0xfinder)`. Requests spaced at least two seconds; no action=parse requests. One exploratory query for ATF, then one batched action=query/prop=extracts/exintro query for ATF, Watson, Malady and CHIRA_JUNIOR. All HTTP 200. Cache the returned extracts here; production makes no Liquipedia calls.

`liquipedia-extracts.json` is an introductory extract from [ATF](https://liquipedia.net/dota2/ATF), [Watson](https://liquipedia.net/dota2/Watson), [Malady](https://liquipedia.net/dota2/Malady), and [CHIRA JUNIOR](https://liquipedia.net/dota2/CHIRA_JUNIOR), by Liquipedia contributors under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Whitespace is the API's output. The small alias table derives Ammar/ATF, watson and Malady from these identities, keyed by the OpenDota account IDs. Full surnames and unused first names would consume biasing budget without being spoken in the clip.
